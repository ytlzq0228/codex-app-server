Claude Code

将下面的地址替换为你访问本站的根地址，不加 /v1。设置后在同一个终端启动 Claude Code，并指定本站提供的模型。

export ANTHROPIC_BASE_URL="https://你的网关地址"
export ANTHROPIC_API_KEY="你的网关Key"
claude --model <可用的Claude模型>

Anthropic Python SDK

from anthropic import Anthropic
import os

client = Anthropic(
    base_url=os.environ["ANTHROPIC_BASE_URL"],
    api_key=os.environ["ANTHROPIC_API_KEY"],
)
message = client.messages.create(
    model="替换为可用的Claude模型",
    max_tokens=1024,
    messages=[{"role": "user", "content": "你好"}],
)
print(message.content)

OpenAI 兼容客户端

Base URL 使用 https://你的网关地址/v1，API Key 使用网关 Key。Responses / Chat Completions 可通过模型名称调用 Codex、Gemini 和 Claude。

Claude 支持文本、图片、客户端工具、流式响应和 JSON Schema（不能与工具同时使用）。工具调用串行执行；Token 计数为估算值。max_tokens、采样与停止参数接受但不控制生成；响应头 x-gateway-generation-policy: worker-defaults 表示使用 Worker 默认生成策略。暂不输出 thinking，也不提供服务端工具或 PDF 输入。
