使用说明

  1. 贡献 Worker：普通用户的名称为“用户名-worker-数字”，只需填写末尾数字。名下有未登录 Worker 时，请先完成登录或删除后再创建。
  2. 生成并使用 Key：在“我的账户”生成 Key，将本站地址加 /v1 作为客户端 API 地址，使用 Authorization: Bearer 你的Key 认证。通过 GET /v1/models 查询可用模型，也可在“查询与调试”中试用。
  3. 维护服务：Worker 退出登录、异常或被删除会失去贡献额度。启用 Key 数量超出额度时，系统优先停用最久未使用的 Key；Worker 恢复后，请手动启用需要的 Key。
  4. 保护账号：不要公开个人 Key；需要更换时可在“我的账户”刷新 Key，旧值立即失效。密码也在“我的账户”中修改。
