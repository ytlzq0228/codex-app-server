# Worker 自动清理

非 mock 网关在启动后及每小时执行一次清理；集群节点仅处理本节点的 Worker。

- 确认连续未登录达到 7 天，删除受管容器并归档 Worker。成功登录会清除计时，重复未登录检测不会重置计时。删除运行中的 Worker 前再次探测，连接失败时暂缓删除。
- Docker 状态为 exited / dead，且 FinishedAt 距今超过 7 天，删除受管容器。包括升级遗留、没有当前 Worker 记录的旧容器。
- 清理前重新检查容器 ID 和停止时间，以非强制方式删除停止容器；已重启或同名替换的容器不会按旧快照删除。
- 当前 Worker 的删除复用手动删除的归档、会话失效及贡献额度回收逻辑；历史审计记录保留。
- 不删除非受管容器、镜像或命名数据卷。升级备份可能与当前容器共享数据卷，删除旧容器不代表其所有磁盘数据都被释放。

已有 Worker 无可靠的连续未登录时间，首次确认未登录时开始计时，不以创建日期或最近检测日期倒推。数据库自动升级新增 nullable `workers.logged_out_since`；关闭自动建表的部署需自行添加 TIMESTAMPTZ 列。
