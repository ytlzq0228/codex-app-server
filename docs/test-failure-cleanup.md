# 工具会话回归测试失败清理

## 原始失败归类

本轮在独立测试数据库重现 26 项失败，与修复工具会话之前的基线一致。

| 类别 | 失败数 | 原因与修正 |
| --- | ---: | --- |
| 丢失工具结果恢复 | 12 | 旧断言要求所有未验证历史报错，未区分恢复旧执行与独立上下文回答。断言失败还中断测试客户端清理，导致后续数据库跨事件循环错误。改为同时验证：持久化证明不成立、无旧 RPC 路由、无执行绑定、工具禁用。 |
| 待处理会话与新用户消息 | 3 | 旧测试假定新用户消息始终返回冲突。现有规则允许取消旧会话并以禁用工具的上下文回答。保留正常工具续接检查，增加取消与恢复审计检查；不完整历史拒绝用例改为没有新用户消息的输入。 |
| Worker 隔离与故障转移 | 5 | 旧测试期待请求路径立即隔离 Worker。现有规则是后台推理探测确认后隔离。更新故障通知模拟边界，验证探测结果决定隔离；后台去重、不阻塞迁移由既有恢复策略用例覆盖。 |
| 测试数据隔离与有效状态 | 2 | Claude 审计检查假定共享池一定选择本测试 Worker；套餐计数用例创建的 Worker 未置为就绪。分别固定测试 Key 的 Worker、补全就绪状态。 |
| 请求审计 | 2 | 旧快照未包含响应交付统计。保留原始请求字段完整比较，并验证响应字节数、块数、断连标志及时间范围。 |
| 页面国际化 | 2 | 中文页面仍期待英文眉题。改为分别覆盖中英文、空列表和有数据列表。 |

这批调整针对过期测试约定与测试数据，不改变运行时行为，也不删除或跳过失败用例。此前工具语法测试已将占位对象替换为真实 `ToolRun`，以支持进度跟踪。
