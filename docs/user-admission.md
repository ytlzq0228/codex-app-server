# 用户准入审核

管理员在“用户准入审核”页面开启或关闭审核，设置保存在数据库，立即对所有节点生效。默认关闭，保留原有 SSO 注册行为。

开启后，首次通过 Google 身份验证的新用户仅写入 pending_users，不创建 users 记录或登录会话。重复登录不会重复提交申请。管理员审批通过时，在同一事务中创建普通用户并删除待审批记录；用户重新使用 Google 登录即可进入系统。

关闭审核只影响后续新申请，已有待审批用户仍须审批。已有正式用户不受审核开关影响，停用账号仍不能登录。管理员手动创建用户始终直接写入 users，保留原有初始密码流程。

系统不会根据邮箱或用户名自动合并 SSO 与本地账号。审批时发现同名正式账号会返回冲突，不覆盖账号、角色或密码。

启动时现有 create_all 流程会创建 admission_config 和 pending_users 两张新表；无需修改现有 users 表。禁用自动建表的部署需先通过现有数据库初始化流程创建新表。
