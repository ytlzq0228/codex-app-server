## 改造结果

- 工具排序和描述改变可继续已认证执行；工具契约改变且有匹配检查点时，取消旧执行并转为无工具回答。

- 自动过期结果恢复在执行锁内重检响应标识；跨节点取消需所属节点确认，超时不启动新执行。

## 边界与后续观察

- 真实部署为单节点测试环境。跨节点身份校验、取消成功/超时使用 ASGI 与数据库集成测试覆盖，未在正式双节点注入故障。
- 无明确身份或可信检查点的过期结果不自动认证放行；有新用户消息和可归一化历史/摘要时可新建会话。显式 previous_response_id、跨账号/会话结果、已领取或重复结果保留原校验。
- 原生 Gemini CLI 本次请求没有明确 thread ID；活跃工具通过 call_id 续接，普通新轮次使用完整输入，不伪造客户端身份。
- 自动工具契约变更恢复覆盖入口可识别的本地挂起执行；远端执行阶段才返回的配置错误可能仍使当轮失败，下一用户轮次可通过所属节点取消后恢复。
- 上游不可用、权限不足、取消无法确认不伪装为成功。provider 权限与 Worker 健康状态的现有授权策略未在本轮修改。
- 后续优先观测恢复后成功率、重复工具执行、客户端压缩及版本模板变化；本轮不宣称穷尽所有客户端组合。
